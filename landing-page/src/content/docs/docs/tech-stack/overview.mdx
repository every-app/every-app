description: Technologies used in Every App

Every App apps are web apps deployed on Cloudflare. We've picked technologies that work well together and are easy for AI coding assistants to work with.

- **[TanStack Start](https://tanstack.com/start)** - Full-stack React framework with TanStack Router and Query
- **[Cloudflare Workers](https://developers.cloudflare.com/workers/)** - Serverless compute with scale-to-zero pricing
- **[D1](https://developers.cloudflare.com/d1/)** - Cloudflare's serverless SQL database
- **[Drizzle ORM](https://orm.drizzle.team/)** - Type-safe SQL ORM

The stack is optimized for simplicity, type safety, and cost (everything scales to zero).
