---
title: Build Your Own App
description: Create a new app using the Every App template
---

Start from the template to get a working app with auth and database already set up correctly with Cloudflare.

```bash
npx @every-app/cli app create
cd your-project-name
pnpm run dev
```

The create command deploys your app to Cloudflare and registers it with your Gateway automatically.

For local development, click the "Dev" button on your app in the Gateway to use your local dev server instead of the deployed version.

## Deploy Updates

After making changes, deploy updates with:

```bash
npx @every-app/cli app deploy
```

This builds your app, runs any pending migrations, and deploys to Cloudflare Workers.
