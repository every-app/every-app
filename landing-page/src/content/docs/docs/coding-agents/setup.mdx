We recommend using an AI coding assistant to build your app. The Every App MCP server gives your agent access to example apps and documentation.

## Setup

<Tabs>

<TabItem label="OpenCode">

Add to `opencode.json`:

```json
{
  "mcp": {
    "every-app": {
      "type": "local",
      "command": ["npx", "-y", "@every-app/mcp"]
    }
  }
}
```

</TabItem>

<TabItem label="Cursor">

Add to `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "every-app": {
      "command": "npx",
      "args": ["-y", "@every-app/mcp"]
    }
  }
}
```

</TabItem>

<TabItem label="Claude Code">

```sh
claude mcp add every-app -- npx -y @every-app/mcp
```

</TabItem>
</Tabs>

Restart your AI tool after adding the MCP server.

## Tips

- **Point to specific examples** - `Look at how the cooking app in Every App handles optimistic mutations` works better than `implement optimistic mutations`
- **Ask questions** - If you're not sure how to do something, ask! `How do migrations work in Every App?` or `Are there any drag and drop Every App examples?`
