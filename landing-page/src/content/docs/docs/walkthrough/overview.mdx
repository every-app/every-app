This walkthrough explains how the [Chef](https://github.com/every-app/every-app/tree/main/apps/every-chef) app is built. Chef is an AI-powered cooking assistant that helps you manage recipes and get cooking guidance through a chat interface.

It covers patterns most apps need like:

- Saving data with instant UI feedback
- Using a component library with light and dark themes
- Organizing backend logic
- Streaming AI responses
- Confirming with user before executing AI actions
