---
title: Deploy the Todo App
description: Put the finished todo app on your Gateway with one command.
---

Your copy of the code comes with a finished todo app in `apps/todo-app`. It syncs live across your devices.

## Deploy it

From your `every-app` folder:

```bash
cd apps/todo-app
pnpm run deploy
```

It goes live at `todo.apps.yourdomain.com`. Open your Gateway and it's in your list of apps.

No Gateway yet? The deploy offers to set one up first.

## Update it

```bash
git pull && pnpm install
cd apps/todo-app
pnpm run deploy
```

Your todos are kept.

## Apps from GitHub

An app whose repository publishes an everyapp release installs with its URL, no clone needed:

```bash
pnpm everyapp deploy https://github.com/owner/repo
```

It deploys the `everyapp-release.tar.gz` on the repository's latest release, already built and checked by its author. Run it again to update to a newer release.

No release on the repository? It says so, and never builds code straight from a URL. Clone it and deploy it from its folder:

```bash
git clone https://github.com/owner/repo apps/repo
cd apps/repo
pnpm install && pnpm everyapp deploy
```

To publish your own app this way, push a tag like `v1.0.0`: apps made with `pnpm everyapp create` include a GitHub workflow that builds the release and attaches it.

## On the hosted Gateway

On the hosted Gateway, an owner or admin can install an app straight from GitHub: **Admin → Apps → Install from GitHub**, then paste the repository's URL. It works for repositories that publish an everyapp release (an `everyapp-release.tar.gz` on their latest GitHub release). For any other repository, clone it and run `pnpm everyapp deploy` with a deploy key from **Admin → Tokens**.
