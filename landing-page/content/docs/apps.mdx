An app is a normal web app. You (or your agent) build the pages and features. Every App handles the rest.

## What every app gets

- **An address**, like `todo.apps.yourdomain.com`, with HTTPS.
- **Its own database**, created on the first deploy.
- **A signed-in user.** The Gateway tells your app who is using it. No login page to build.
- **AI without keys.** AI requests go through the Gateway, which adds your key.

## Private by default

Your app has no public address of its own. The only way in is through the Gateway. So if your agent forgets to protect a page, it's still private.

## Try it on your computer

```bash
pnpm dev
```

Run this in the app folder. Your app opens at `http://<app-name>.localhost:8787`, signed in as a test user. Changes show up right away.

## A note for your agent

Every new app includes `.agents/skills/everyapp/SKILL.md`. It teaches your coding agent how Every App works, so you don't have to.
