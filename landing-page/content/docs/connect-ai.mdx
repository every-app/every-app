---
title: Use your apps from Claude or ChatGPT
description: Connect Claude, ChatGPT, Claude Code or Cursor to your Gateway once, and they can use every app you can open.
---

Your Gateway has one address for AI assistants, and it covers all your apps:

```text
https://apps.yourcompany.com/mcp
```

Connect it once. The assistant signs in to your Gateway as you, asks which apps it may use, and from then on it can read and change things in those apps the way you can. An app only offers what its builder made available, and nothing that deletes data.

Your Gateway can also offer a data provider it holds a key for, like DataForSEO, to assistants as an MCP app: `pnpm everyapp mcp on dataforseo`. It has no page; it shows under "MCP apps" on the home page, and its card says how to use it from your assistant.

## Claude and ChatGPT

In Claude (claude.ai or the desktop app) or ChatGPT, add a custom connector and paste the address above. Your Gateway's sign-in page opens: sign in, choose the apps and whether the assistant may change things or only read, and allow it.

## Claude Code

In a terminal, run:

```bash
claude mcp add --transport http everyapp https://apps.yourcompany.com/mcp
```

Then type `/mcp` in Claude Code, choose **everyapp** and **Authenticate**. Allow it in the page that opens.

## Cursor and other tools

Add an MCP server with the address above. Tools that can't sign in on their own take a personal access token instead. An owner or admin makes one for you: in the Gateway, open **Manage workspace**, then **Tokens**, select **New token**, and give the token to the tool as the `Authorization: Bearer` header.

## Disconnect

In the account menu at the bottom of the Gateway's sidebar, open **AI connections** to see every connection and revoke one. Deactivating a person disconnects all of theirs.

This works behind [Cloudflare Access](/docs/access) too. For how tools, sign-in and tokens work underneath, ask your agent or see the [agent docs](/docs/agent/mcp).
