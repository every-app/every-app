---
title: Connect your AI
description: Connect Claude, ChatGPT, Claude Code, Codex or Cursor to your Gateway once, and they can use every app you can open.
---

Connect your assistant once and it can use every app you can open, the way you can. It uses one address:

```text
https://apps.yourcompany.com/mcp
```

In the Gateway, open **Your connections** in the sidebar, then **Agents**. It shows your address and the steps for each assistant. Once an agent is connected, select **Connect an agent** to see them again.

## Claude and ChatGPT

Add a custom connector and paste the address.

## Claude Code

```bash
claude mcp add --transport http everyapp https://apps.yourcompany.com/mcp
```

Then type `/mcp` in Claude Code, choose **everyapp** and **Authenticate**.

## Codex

```bash
codex mcp add everyapp --url https://apps.yourcompany.com/mcp
codex mcp login everyapp
```

## Cursor

Add this to `~/.cursor/mcp.json` (or `.cursor/mcp.json` in a project). Cursor then asks you to sign in.

```json
{ "mcpServers": { "everyapp": { "url": "https://apps.yourcompany.com/mcp" } } }
```

## What happens next

A sign-in page opens. Choose the apps, choose read & write or read only, and allow it. Tools that delete are marked, so your assistant can ask you first.

Tools that can't sign in take a personal access token as an `Authorization: Bearer` header. An owner or admin makes one in **Manage workspace** → **Tokens**: read only or full access, for every app or one, for 7 days to a year.

## Add tools from elsewhere

Your Gateway can also offer tools from another MCP server, as an MCP app. Its key stays on the Gateway, never in your assistant. A server that uses sign-in (OAuth) asks each person to connect their own account once.

```bash
everyapp mcp on dataforseo
everyapp mcp add https://mcp.example.com/mcp
```

Or, in the Gateway: **Manage workspace** → **Apps** → **Add MCP server**.

## Disconnect

Open **Your connections** in the sidebar, then **Agents**, and revoke a connection.

Full reference: [MCP](/docs/agent/mcp).
