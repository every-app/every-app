## The fast path: paste this into your agent

```text
Help me build an Every App application (docs: https://everyapp.dev/llms.txt).

1. Run `npx -y everyapp app create`. When it asks for an app name, pause and
   ask me. Then move into the folder it created.
2. Ask me what app I want to build, then build it.
3. Start local dev with `npx everyapp dev` and give me the local URL to open.
4. When I say I'm happy with it, deploy with `npx -y everyapp app deploy -y`
   and tell me to refresh my Gateway.

Pause and tell me exactly what to do whenever a step needs me. If a command
needs interactive input you can't provide, give me the exact command to run
in my own terminal.
```

The manual steps, if you'd rather drive:

## 1. Create the app

```bash
npx everyapp app create
cd your-app-name
```

The command asks you to name your app; `cd your-app-name` means move into the folder it created, using the name you chose.

This creates a working app from our starter template, deploys it to your Cloudflare account, and registers it with your Gateway. Before you write a line of code, you have a real full-stack app with a database, running behind your Gateway's login.

## 2. Describe what you want

Open the project in your coding agent and describe your app. A short prompt works:

```md
Please make me a task management tool. My goal is a minimal tool where I can
track the state of tasks within multiple projects.

There should be a page for the board and a page for editing each task. It
should support multiple boards, and a flow to invite other users to my board
by email.
```

The more detail you give, the closer the first draft lands to your vision. You don't need everything figured out; the agent fills gaps sensibly and you iterate from there.

## 3. Run it locally

```bash
npx everyapp dev
```

Open `http://<your-app-id>.localhost:8787` — for an app named `tasks`, that's `http://tasks.localhost:8787`. Edits show up in the browser instantly, you get a local database, and login works the same as production. [Local Development](/docs/build-an-app/local-dev) covers this in depth.

When your agent adds or changes what the app stores, generate a migration for the change:

```bash
pnpm run db:generate
```

Restarting `everyapp dev` applies it to your local database automatically (or run `pnpm run db:migrate:local` without restarting).

## 4. Deploy

```bash
npx everyapp app deploy
```

This builds the app, runs pending database migrations, and deploys to your Cloudflare account. Refresh your Gateway and the changes are live.

## What you can build

Anything Cloudflare can host, which is a lot: [Workers, databases (D1), key-value storage, queues, AI, and more](https://developers.cloudflare.com/directory/?product-group=Developer+platform). Apps are built on [TanStack Start](https://tanstack.com/start/latest), a modern full-stack React framework.

Our example apps follow consistent patterns so agents produce high-quality code.
