Run these in a terminal, inside your `every-app` folder. Add `--help` to any command to see all its options.

## Run a Gateway

| Command                              | What it does                                                                                 |
| ------------------------------------ | -------------------------------------------------------------------------------------------- |
| `pnpm everyapp login`                | Logs in to Cloudflare.                                                                       |
| `pnpm everyapp setup`                | Installs your Gateway. Run it again to resume or repair.                                     |
| `pnpm everyapp update`               | Updates your Gateway to the version in your folder.                                          |
| `pnpm everyapp install <GitHub URL>` | Installs an app someone published on GitHub.                                                 |
| `pnpm everyapp status`               | Shows your Gateway and apps, and what to run if needed. [Every line explained](/docs/status) |
| `pnpm everyapp delete my-app`        | Takes an app off your Gateway. `--purge` deletes its data.                                   |
| `pnpm everyapp secret set <NAME>`    | Stores one key, like `OPENAI_API_KEY`, without showing it.                                   |
| `pnpm everyapp configure my-app`     | Sets up an app: asks for each key it needs, then the optional ones.                          |
| `pnpm everyapp access on`            | Puts Cloudflare Access in front of your Gateway and apps.                                    |

## Build an app

| Command                       | What it does                                        |
| ----------------------------- | --------------------------------------------------- |
| `pnpm everyapp create my-app` | Makes a new app from the starter, in `apps/my-app`. |
| `pnpm everyapp release`       | Packs the app as a release others can install.      |

## Inside an app's folder

| Command                    | What it does                                                                              |
| -------------------------- | ----------------------------------------------------------------------------------------- |
| `pnpm dev`                 | Runs the app on your computer.                                                            |
| `pnpm run deploy`          | Puts the app online, or updates it.                                                       |
| `pnpm run db:generate`     | Writes a migration after what the app stores changes.                                     |
| `pnpm everyapp db restore` | Puts the app's database back to before its last migration, losing anything written since. |

There's also `email` for the addresses an app sends from and receives at, `secret list` and `secret unset` for what an app needs set, `mcp on` to offer DataForSEO to AI assistants as an MCP app, `workspace rename` to rename the workspace, `access off` and `access show` for [Cloudflare Access](/docs/access), `db` for looking inside a database, and `teardown`, which empties a Cloudflare account set aside for testing and refuses any other.
