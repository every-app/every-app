---
title: Connect GitHub (or any OAuth provider)
description: Let your apps use people's GitHub, Google, Notion or other accounts. You add the provider once; each person connects their own account in each app that needs it.
---

Your apps can work with a person's GitHub repositories, Google Search Console or Notion pages. You add the provider once. Each person connects their account inside each app that needs it, and that connection belongs to them and that app. Apps never see the tokens.

## Add a provider

An owner or admin does this once per provider.

1. Open **Manage workspace** → **Providers** → **Add OAuth provider**.
2. Pick the provider, or **Custom** for one that isn't listed.
3. Copy the **redirect URI** the dialog shows, like `https://apps.yourcompany.com/connect/github-oauth/callback`.
4. At the provider, create an OAuth app with that redirect URI. For GitHub: **Settings → Developer settings → OAuth Apps → New OAuth App** (an OAuth App, not a GitHub App).
5. Paste the client id and client secret into the dialog and select **Add**.

Or from a terminal. It prints the redirect URI, then asks for the client id and secret:

```bash
everyapp provider add github-oauth
```

Steps for each provider's console: [GitHub](/docs/providers/github#connect-accounts), [Google](/docs/providers/google#connect-accounts), [Microsoft 365](/docs/providers/microsoft#connect-accounts), [Slack](/docs/providers/slack#connect-accounts), and [the rest](/docs/providers).

To change the secret later, select the provider's **⋯** → **Replace client**.

## Connect your account

Connect from inside the app:

1. Open the app and select its **Connect GitHub** button (or the provider's name).
2. The provider shows exactly the scopes that app asks for. Allow them.
3. You're back in the app.

The app can now use your account whenever it needs to, including for work that runs while you're away, like a nightly sync. Another app that needs the same provider asks you to connect again, for its own scopes.

Each app lists the provider's own scopes in its `everyapp.config.ts`. If the provider hands back a token with more scopes than the app listed, the Gateway refuses it and drops it.

If a connection expires, or the app now needs a scope it didn't before, the app shows **Reconnect**.

## Disconnect

Open **Connections** in the sidebar, then **Accounts**. It lists each connection with the app it belongs to. Open a connection's menu and select **Disconnect**, and that app stops using it at once. An owner or admin can disconnect anyone's connection in **Manage workspace** → **Providers**.

Removing a person from the workspace disconnects all their accounts. Losing access to an app disconnects their account from that app. Deleting an app or removing a provider disconnects everyone from it.

For the full reference, see [OAuth providers](/docs/agent/providers#oauth-providers-upload-a-client-the-gateway-runs-the-flow).
