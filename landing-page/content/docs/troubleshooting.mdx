---
title: Troubleshooting
description: What the most common messages mean and how to fix them.
---

Two things fix most problems:

- **Run the same command again.** Setup and deploys pick up where they stopped.
- **Run `pnpm everyapp status`.** It shows what's wrong and what to run.

## Subscribe this account to Workers Paid

Your Cloudflare account is on the free plan. [Turn on Workers Paid](/docs/cloudflare#turn-on-workers-paid), then run the command again. Nothing was created.

If you see **Couldn't confirm this account is on Workers Paid**, setup carries on. Check that you've subscribed.

## Add a domain to this Cloudflare account

The Cloudflare account you logged in to has no domain. [Get a domain](/docs/domain), then run the command again. If you have more than one Cloudflare account, check you approved the login for the right one.

## Finish activating your domain on Cloudflare

Its nameservers don't point to Cloudflare yet. Finish [the nameserver step](/docs/domain#use-a-domain-you-already-own), wait for Cloudflare's email saying the domain is active, then run the command again.

## Choose a workers.dev subdomain for this Cloudflare account

Cloudflare asks every account to pick this name once. Open the link the terminal shows, pick any name, and run the command again. Your apps never use it.

## Your address already points somewhere else

Something on your domain already uses the address you chose. Delete that record in Cloudflare (your domain, then **DNS**), or choose another address.

## You lost the owner link, or it stopped working

Run `pnpm everyapp setup` again for a new link.

## A new address doesn't load yet

Cloudflare is still making its HTTPS certificate. Give it up to ten minutes.

## An app in your Gateway says Needs deploy, Deploying or Disabled

- **Needs deploy:** the app isn't online yet. Run `pnpm run deploy` in its folder.
- **Deploying:** the app is still being connected. Refresh in a minute.
- **Disabled:** the app has been turned off.

## The schema has changes no migration covers

Your app stores something new but has no migration for it. In the app's folder, run `pnpm run db:generate`, then deploy again.

## This checkout's Gateway is older than the live one

Someone updated your Gateway from a newer copy of Every App. In your `every-app` folder, run `git pull` and `pnpm install`, then try again.

## Your every-app folder has a newer Gateway than the one online

Not a problem. Run `pnpm everyapp gateway deploy` to update it, or leave it: the next new app you deploy updates it too.

## everyapp needs Node.js 22.18.0 or newer

Install the latest LTS version from [nodejs.org](https://nodejs.org), open a new terminal window, and try again.

## Command "everyapp" not found

You're outside your `every-app` folder, or haven't run `pnpm install` in it yet. Run `cd every-app`, then `pnpm install`, and try again.

## No everyapp.config.ts in this directory

This command runs inside an app's folder. Run `cd apps/my-app` and try again.

## Strange errors after using npx

`npx everyapp` downloads an old version that doesn't work. A copy installed with `npm install -g` runs from outside your folder and says **everyapp has to run from a checkout of the Every App repository**. Always run `pnpm everyapp` from your `every-app` folder.

## Still stuck

Run the command again with `--verbose` at the end, and bring the output to our [Discord](https://discord.gg/c9uGs3cFXr).
