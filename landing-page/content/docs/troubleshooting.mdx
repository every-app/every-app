---
title: Troubleshooting
description: The most common problems and how to fix them.
---

Two things fix most problems. **Run the command again:** `setup` and `deploy` pick up where they stopped. **Ask `pnpm everyapp status`:** it tells you what's wrong and what to run.

## Odd errors after using npx

Running the CLI through npx downloads an old version that doesn't work. Always run `pnpm everyapp` from your `every-app` folder.

## "Every App needs a domain on Cloudflare"

The Cloudflare account you're logged in to doesn't have that domain. Add it to Cloudflare, or buy one under **Domains → Buy a domain**, then run the command again.

## "Couldn't confirm this account is on Workers Paid"

Subscribe under **Workers & Pages → Plans** in the Cloudflare dashboard. If you already have, setup carries on anyway.

## "No workers.dev subdomain yet"

Cloudflare wants every account to pick one name once. Open the link the CLI shows, pick any name, and run the command again.

## You lost the owner account link

Run `pnpm everyapp setup` again for a new one.

## The address doesn't load yet

New addresses need an HTTPS certificate from Cloudflare. It usually takes a minute or two, sometimes up to ten.

## "Schema has changes its migrations don't"

Your database changed but nobody wrote down the change. In the app folder, run `pnpm run db:generate`, then `pnpm run deploy`.

## "No everyapp.config.ts found"

You're not in an app folder. Run `cd apps/my-app` and try again.

## Still stuck

Run the command again with `--verbose`, then open an issue on [GitHub](https://github.com/every-app/every-app/issues) with the output.
