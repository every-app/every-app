---
title: Create an app
description: Start from the starter, tell your coding agent what you want, and put it online.
---

You need pnpm (`npm install -g pnpm`) and git.

<Steps>
<Step>

### Create it

```bash
everyapp create my-app
cd my-app
```

You get a small todo app in its own git repository. The name becomes its address, `my-app.apps.yourcompany.com`.

</Step>
<Step>

### Tell your agent what you want

Open the `my-app` folder in your coding agent and describe the app:

```text
Turn this into a shared todo list for my household. I want separate lists
for groceries and chores, a due date on each todo, and a way to see who
added what.
```

You don't need a login page. The Gateway handles sign-in, and the app includes notes that explain EveryApp to your agent.

</Step>
<Step>

### Try it on your computer

```bash
pnpm dev
```

Open `http://my-app.localhost:8787`. You're signed in as a test user, and changes show up as your agent makes them.

</Step>
<Step>

### Put it online

```bash
pnpm run deploy
```

The app is now at `https://my-app.apps.yourcompany.com`, private to owners and admins. To share it, see [Invite people](/docs/people#choose-who-can-open-an-app).

</Step>
</Steps>

To ship a change later, run `pnpm run deploy` again. [Update and remove](/docs/update)

## When your app needs more

- **AI.** Ask your agent for the feature. The app calls a model through your Gateway and never holds a key. Add the key once with `everyapp provider add openrouter`. [AI models](/docs/ai)
- **A key of its own.** Your agent lists it in `everyapp.config.ts`. After you deploy, run `everyapp configure my-app` and paste the key. For `pnpm dev`, put it in the app's `.dev.vars` file.
- **A database, files or queues.** [Cloudflare resources](/docs/resources)
- **Other people installing it.** Run `everyapp release` in its folder and attach the file to a GitHub release. They run `everyapp install https://github.com/owner/repo`.
