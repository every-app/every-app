Every App uses a modern stack that's straightforward for developers and AI coding agents alike.

| Technology                                                       | What it does                        |
| ---------------------------------------------------------------- | ----------------------------------- |
| [TanStack Start](https://tanstack.com/start)                     | Full-stack React framework          |
| [Cloudflare Workers](https://developers.cloudflare.com/workers/) | Serverless hosting (scales to zero) |
| [D1](https://developers.cloudflare.com/d1/)                      | SQL database                        |
| [Drizzle ORM](https://orm.drizzle.team/)                         | Type-safe database queries          |

## Why this stack?

- **Type-safe end to end** - Catch errors before they happen
- **Scales to zero** - You only pay for what you use
- **AI-friendly** - Common patterns that coding agents understand well
