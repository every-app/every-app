Your Gateway can tell other tools when something happens: someone joins, an app is installed, an app nears its monthly cap, an AI assistant's call is blocked. Pick the events and a web address, and the Gateway sends each one there, signed.

## Add a webhook

Open **Manage workspace** at the bottom of the sidebar, then **Events**, and select **Add subscription**. Choose **Webhook**, paste the address, tick the events (or **Everything**), and save. Or:

```bash
everyapp events add https://hooks.example.com/everyapp --events 'cap.*,member.*'
```

The address must be public `https://`. `cap.*` means every cap event; leave `--events` out to send everything. The signing secret is shown once: copy it if your receiver will [check the signature](#check-the-signature). Send a test with **Send test** in the row's menu, or `everyapp events test <id>`.

## Post to Slack

In Slack's Workflow Builder (paid plans), start a workflow **From a webhook**, add a text variable `summary`, add a **Send a message to a channel** step with `{{summary}}`, publish, and add Slack's webhook address here. Each event arrives as one line, like "crm is at 80% of its monthly cap ($16.00 of $20.00)".

A classic Slack incoming webhook (`https://hooks.slack.com/services/...`) won't work directly. Put Zapier, n8n or Make in between and post the `summary` field.

## Email alerts

Once you set a cap in [Usage](/docs/usage), owners and admins get an email at 80% of it and at the cap. It shows as **Cap alerts** under **Events**; switch it off there.

To email other events, choose **Email** in **Add subscription**, or:

```bash
everyapp events add --email admins --events 'member.*'
```

`admins` mails owners and admins; `owners` mails owners only. Your Gateway needs to [send email](/docs/people#send-email).

## Check the signature

Each delivery has an `X-EveryApp-Signature` header like `t=1761383703,v1=5f0c…`. Compute an HMAC-SHA256 of the timestamp, a dot and the raw body with the subscription's secret, compare it with `v1`, and refuse timestamps more than five minutes off. In Node.js:

```js
import { createHmac, timingSafeEqual } from "node:crypto";

export function verifyEveryApp(
  secret,
  header,
  rawBody,
  now = Date.now() / 1000,
) {
  let timestamp = null;
  const signatures = [];
  for (const part of (header ?? "").split(",")) {
    const [key, value = ""] = part.trim().split("=", 2);
    if (key === "t" && /^\d+$/.test(value)) timestamp = Number(value);
    if (key === "v1") signatures.push(Buffer.from(value, "hex"));
  }
  if (timestamp === null || signatures.length === 0) return false;
  if (Math.abs(now - timestamp) > 300) return false;
  const expected = createHmac("sha256", secret)
    .update(`${timestamp}.`)
    .update(rawBody)
    .digest();
  return signatures.some(
    (given) =>
      given.length === expected.length && timingSafeEqual(given, expected),
  );
}
```

Python and Go versions are in the [Events reference](/docs/agent/events#the-signature).

Answer with any 2xx within 10 seconds. The same event can arrive twice; skip an `id` you've already seen.

## When the receiver is down

A failed delivery is retried six times over about 35 hours, then marked **Dead**. Open the subscription's **Deliveries** to see each try, fix the receiver, and select **Redeliver**. Or:

```bash
everyapp events deliveries --dead
everyapp events redeliver <delivery id>
```

## The events

Events come in families: people (`member.*`), apps (`app.*`), caps (`cap.*`), groups (`group.*`), AI tool calls (`tool.*`), connections and tokens (`connection.*`, `token.*`), providers (`provider.*`, `mcp_app.*`, `signin_provider.*`), Cloudflare Access (`access.*`) and AI defaults (`ai.*`). To list every event with what it means:

```bash
everyapp events types
```

Apps can send their own events too, named `app.<app id>.<name>`, like `app.crm.invoice.paid`. To get every event one app sends, subscribe to `app.crm.*`.

An event never holds a password, a token, an invitation or reset link, what an AI assistant sent to a tool or got back, or the text of an email.

For the full reference, with every field of every event, give your coding agent [Events](/docs/agent/events).
