> **AI meeting notes for Mac.**
>
> Every App for Mac records and transcribes your meetings. OpenScribe turns each transcript into notes and keeps them on your Gateway. Audio is never stored.

Notes are private by default. You can share them with your workspace, or publish one with a link you can revoke. In the app it's called Scribe.

## Install

Enable R2 in your Cloudflare dashboard first (R2 Object Storage, then Get started).

```bash
everyapp install https://github.com/every-app/open-scribe
```

Then it asks for:

- `OPENAI_API_KEY` (required): transcribes the meeting and writes the notes.
- Optional: a Google Workspace OAuth client, so it can remind you when a meeting starts ([Connect accounts](/docs/connect-oauth)).

Run the install command again to update. `everyapp configure scribe` changes a key later. The app's id is `scribe`.

## Record a meeting

Download Every App for Mac from [everyapp.com/openscribe](/openscribe). Sign in with your Gateway's address, like `apps.yourcompany.com`. The app's own address, `https://scribe.apps.yourcompany.com`, works too.

Code: [github.com/every-app/open-scribe](https://github.com/every-app/open-scribe)
