> **SEO research you pay for by use, not by the month.**
>
> Keyword research, rank tracking, backlinks, site audits and AI visibility, on DataForSEO data billed per call. Claude Code, Codex, Cursor or ChatGPT can work with it through MCP.

You get keyword research, scheduled rank tracking, competitor and backlink profiles, page-by-page site audits, AI visibility (which sites AI answers cite in your market), and Search Console and GA4 beside the research. SAM, its built-in agent, can do any of it for you.

## Install

Enable R2 in your Cloudflare dashboard first (R2 Object Storage, then Get started).

```bash
everyapp install https://github.com/every-app/open-seo
everyapp configure openseo
```

`configure` asks for:

- `OPENROUTER_API_KEY` (required): SAM and website research run on it.
- `DATAFORSEO_API_KEY` (required): `login:password` from your DataForSEO dashboard.
- Optional: `CONTEXT_API_KEY` to render JavaScript-heavy pages in audits, and a Google Workspace OAuth client for Search Console and GA4 ([Connect an OAuth provider](/docs/connect-oauth)).

DataForSEO bills per call. Set a cap so the Gateway stops the app before you overspend: [Usage and caps](/docs/usage).

Run the install command again to update. Every member of your workspace can open it.
