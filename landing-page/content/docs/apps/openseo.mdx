> **SEO research you pay for by use, not by the month.**
>
> Keyword research, rank tracking, backlinks, site audits and AI visibility, on DataForSEO data billed per call. Claude Code, Codex, Cursor or ChatGPT can work with it through MCP.

## Features

- Keyword research: volume, CPC, difficulty, intent, trends and a SERP analysis.
- Rank tracking on a schedule.
- Domain overview and competitor insights.
- Backlink profiles for your site or a competitor's.
- Site audits, page by page.
- AI visibility: what people ask AI in your market and which sites get cited.
- Search Console and GA4 beside the research.
- An agent, SAM, and every tool served to your AI clients over MCP.

## Install on EveryApp

```bash
pnpm everyapp install https://github.com/every-app/open-seo
pnpm everyapp configure openseo
```

Needs an OpenRouter key, a DataForSEO key, and R2 enabled on your Cloudflare account. Code: [github.com/every-app/open-seo](https://github.com/every-app/open-seo)

### Settings

The second command asks for each key below, then the optional ones. Run the first again later to update. DataForSEO bills by use; the Gateway counts the calls and stops the app at a cap you set. [Usage and caps](/docs/usage)

| Setting                                                           | Held by | Needed   | Why                                                                                                                                                                      |
| ----------------------------------------------------------------- | ------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OPENROUTER_API_KEY`                                              | Gateway | Yes      | SAM, prompt suggestions and website research run on it.                                                                                                                  |
| `DATAFORSEO_API_KEY`                                              | Gateway | Yes      | Keyword, SERP, backlink, local business and AI answer data, including scheduled rank checks. The value is `login:password` from the DataForSEO dashboard, or its base64. |
| `CONTEXT_API_KEY`                                                 | Gateway | Optional | Renders JavaScript-heavy pages when a site audit asks for it.                                                                                                            |
| `GOOGLE_WORKSPACE_CLIENT_ID` and `GOOGLE_WORKSPACE_CLIENT_SECRET` | Gateway | Optional | Search Console and GA4 reads for your sites, with the Google account you connect in EveryApp. [Connect an OAuth provider](/docs/connect-oauth)                           |
| `CRAWLER_ACCESS_SECRET`                                           | OpenSEO | Optional | Encrypts the Shopify crawler-access signatures that audits of protected stores send. Any string of 32 or more characters.                                                |
| `OPENROUTER_MODEL`                                                | OpenSEO | Optional | Picks the OpenRouter model for SAM, prompt suggestions and website research. The default is `openai/gpt-5.6-luna`.                                                       |

Nothing in OpenSEO is public: every page needs a signed-in member. Once installed, every member of your workspace can open it.
