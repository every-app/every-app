Each app is open source and runs in your own Cloudflare account. Run it as it is, or have your agent change it.

- [OpenSEO](/docs/apps/openseo): SEO research you pay for by use, not by the month.
- [OpenCRM](/docs/apps/crm): A CRM that fills itself in.
- [OpenScribe](/docs/apps/openscribe): Meeting notes for Mac, saved in your own Cloudflare account.
- [OpenAnalytics](/docs/apps/analytics): Web analytics on your own Cloudflare account. No cookies.
- [OpenMail](/docs/apps/openmail): An inbox where an AI agent drafts your replies and you hit send.

## Install one

Turn on R2 in your Cloudflare dashboard once (R2 Object Storage, then Get started). Every app but OpenAnalytics stores files there.

```bash
everyapp install https://github.com/every-app/open-crm
```

The install asks for the keys the app needs. Each app's page lists them. If you skip one, the app shows **Needs setup** until you run `everyapp configure crm`.

To update an app, run its install command again. Your data stays.

Every member of your workspace can open an installed app. [Invite people](/docs/people)
