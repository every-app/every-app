> **Keep the GitHub traffic history GitHub drops after 14 days.**
>
> RepoLens captures views, clones, referrers, stars, forks and release downloads every six hours into a database in your own Cloudflare account. Your read-only GitHub token stays on your Worker.

You get views, clones, referrers and popular paths kept past 14 days, star and fork history backfilled when you start tracking, release downloads by day, CSV export, and a stars badge with a 30-day sparkline for your README.

## Install

The repository is private for now, so there is nothing to install from yet. If you have access, clone it, run `pnpm install`, then `pnpm run deploy` in its folder. Once it is public:

```bash
everyapp install <its repository URL>
everyapp configure repolens
```

`configure` asks for one key:

- `GITHUB_TOKEN` (required): a classic token with the `repo` scope, or a fine-grained token with Administration, Contents and Metadata read. Traffic needs Administration. Don't use the GitHub CLI's token: some organizations block it, and star history then fails.

Badges at `/badge/OWNER/REPO.svg` are public, even for private repositories, so anyone who knows a tracked repository's name can see its star count. Everything else needs sign-in.

A new install opens only for owners and admins. Grant others under **Admin → Apps** on your Gateway.
