> **A CRM that fills itself in.**
>
> Add a company and a research agent finds its website, logo and people. Connect Gmail or Outlook and your conversations and meetings land on the right records.

You get companies, contacts, deals, tasks and notes, with custom fields and saved views. The agent briefs you before meetings. Mail and calendar capture is read only: it never sends or drafts mail. Website visitors and form submissions become contacts.

## Install

Enable R2 in your Cloudflare dashboard first (R2 Object Storage, then Get started).

```bash
everyapp install https://github.com/every-app/open-crm
everyapp configure crm
```

`configure` asks for:

- A model key (required). `OPENROUTER_API_KEY` is the one to pick; it also turns on web research.
- `CONTEXT_API_KEY` (required): company data, LinkedIn profiles and website extraction.
- Optional: Google Workspace or Microsoft 365 OAuth clients to capture mail and meetings, and a Slack client for team agents ([Connect an OAuth provider](/docs/connect-oauth)). Set `TOKEN_ENCRYPTION_KEY` (32 or more random characters) before anyone connects them.

Researching a record costs at most about $0.25 in model and Context.dev calls, plus web searches.

Run the install command again to update. Every member of your workspace can open it.

## Use it from your agent

[Connect your agent](/docs/connect-ai) to your Gateway, then ask things like "Brief me on my 2pm meeting" or "Add Acme and research it."
