> **A simple CRM.**
>
> Connect Gmail or Outlook and your conversations and meetings land on the right companies and contacts.

You get companies, contacts, deals, tasks and notes, with custom fields and saved views. Mail and calendar capture is read only: it never sends or drafts mail. Website visitors and form submissions become contacts.

## Install

Enable R2 in your Cloudflare dashboard first (R2 Object Storage, then Get started).

```bash
everyapp install https://github.com/every-app/open-crm
```

It needs no keys to open. To capture mail and meetings, add a Google Workspace or Microsoft 365 OAuth client ([Connect accounts](/docs/connect-oauth)), then each person connects their own account in the app.

Run the install command again to update. `everyapp configure crm` sets up mail capture later. Every member of your workspace can open it.

## Use it from your agent

[Connect your agent](/docs/connect-ai) to your Gateway, then ask things like "What did we last discuss with Acme?" or "Add Acme as a company."
