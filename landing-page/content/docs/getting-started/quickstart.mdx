Two things happen in this guide: you deploy your Gateway to your own Cloudflare account on your own domain, then you install an example app. Every app gets its own address under your domain. Throughout these docs, we use `your-domain.dev` for the Gateway and addresses such as `todo-<your-org>.your-domain.dev` for apps. The suffix is your organization slug, created with your account.

<Callout type="info">
  `your-domain.dev` is a placeholder. Your domain can use any extension. If you
  don't own one, you can buy one for about $10 a year from any registrar,
  including [Cloudflare](https://developers.cloudflare.com/registrar/). The
  Gateway can deploy without a domain for a quick look around, but apps only
  become reachable once your domain is set up.
</Callout>

## The fast path: let your agent set you up

Paste this prompt into your coding agent and follow along. The agent runs the commands; you only step in for the things it can't do alone: creating accounts, clicking a browser login, and one DNS record.

Don't have a coding agent yet? Install [Claude Code](https://claude.com/claude-code) or [Cursor](https://cursor.com), open its chat, and paste the prompt there.

```text
Help me set up Every App, a self-hosted platform for personal apps on my own
Cloudflare account and domain. Docs for you: https://everyapp.dev/llms.txt

Do these steps in order. Run the commands yourself. Pause and tell me exactly
what to do whenever a step needs me (creating an account, clicking a browser
login, adding a DNS record). If a command needs interactive input you can't
provide, give me the exact command to run in my own terminal.

1. Ask me where my Every App projects should live, create that folder, and
   run everything from inside it.
2. Check Node.js is installed (`node --version`, must be 22.18 or newer).
   Help me install it if not.
3. If I don't have a Cloudflare account, send me to
   https://dash.cloudflare.com/sign-up and wait. It's free, no credit card.
4. Ask me which domain I want to use. If it isn't on my Cloudflare account
   yet, walk me through "Add a domain" at https://dash.cloudflare.com (free
   plan is fine) and updating the nameservers at my registrar. If I don't own
   a domain, help me buy one first (Cloudflare Registrar or any registrar).
5. Run `npx -y cf auth login` in my terminal. It prints a link and a
   one-time code; tell me to open the link, check the code and approve. If
   that login can't complete, walk me through creating an API token at
   https://dash.cloudflare.com/profile/api-tokens with the "Edit Cloudflare
   Workers" template plus Account → D1 → Edit permission, then export
   CLOUDFLARE_API_TOKEN and CLOUDFLARE_ACCOUNT_ID before continuing.
6. Run `npx -y everyapp gateway deploy -y --printSetupLink --domain <my domain>`.
   If it prints instructions for adding a wildcard DNS record (CNAME, name
   "*", target my domain, proxy ON), pause and walk me through adding it in
   the Cloudflare dashboard under my domain → DNS.
7. When it finishes, give me the one-time setup link it printed
   (https://<my domain>/setup#token=…) and tell me to open it and create my
   account there.
8. Tell me to create a deploy token: on my Gateway, Admin → Tokens →
   Deploy token (it's shown once — copy it). Then run
   `npx -y everyapp login` and I'll paste the token when it asks. This is
   what lets this machine deploy apps to my Gateway.
9. Ask if I want an example app installed. If yes:
   npx -y gitpick every-app/every-app/tree/main/apps/todo-app every-todo-app
   cd every-todo-app && npx -y everyapp app deploy -y
10. Tell me to refresh my Gateway. The app appears there, live at its own
    subdomain of my domain.

Keep responses short, one step at a time. If a command fails, show me the
error and your suggested fix before retrying.
```

## The manual path

The same steps, if you'd rather run them yourself.

### 1. Prerequisites

1. Install [Node.js](https://nodejs.org/) 22.18 or newer. This includes `npx`, which runs the commands below.
2. [Create a Cloudflare account](https://dash.cloudflare.com/sign-up) — free, no credit card.
3. [Add your domain to Cloudflare](https://developers.cloudflare.com/fundamentals/manage-domains/add-site/) (free plan is fine) and update the nameservers at your registrar. Skip this if your domain already lives on Cloudflare.
4. Log in to Cloudflare from your terminal with Cloudflare's CLI:

   ```bash
   npx cf auth login
   ```

   It prints a link and a one-time code. Open the link, check the code and approve. (The deploy offers this login too if you skip it.)

### 2. Deploy the Gateway

```bash
npx everyapp gateway deploy --domain your-domain.dev
```

This sets up a database and hosting on your Cloudflare account, puts the Gateway live at your domain, and points `*.your-domain.dev`, every future app address, at it.

That last part needs one DNS record. Add it once in the dashboard (the deploy reminds you if it's missing):

> **your-domain.dev → DNS → Add record**: Type **CNAME**, Name **`*`**, Target **`your-domain.dev`**, Proxy **ON** (orange cloud).
>
> It means "any subdomain of your-domain.dev goes to the same place as your-domain.dev itself": your Gateway, which serves the right app for each address. Cloudflare requires an explicit record for [wildcard routing](https://developers.cloudflare.com/workers/configuration/routing/routes/).

When the deploy finishes, it prints (and opens) a one-time setup link, `https://your-domain.dev/setup#token=…`. Open it and create your account: you're the owner, and signup is invite-only after you. Nobody can sign up before you use the link. It expires after 24 hours; `npx everyapp gateway claim-link` makes a new one.

### 3. Connect your terminal to your Gateway

On your Gateway, go to **Admin → Tokens → Deploy token** and copy the token (it's shown once). Then:

```bash
npx everyapp login
```

Paste the token when asked. This is what authorizes app deploys from this machine — revoke it any time from the same page.

### 4. Install an example app

The first command (`gitpick`) just copies the example app's folder from GitHub; the second deploys it.

```bash
npx gitpick every-app/every-app/tree/main/apps/todo-app every-todo-app
cd every-todo-app
npx everyapp app deploy
```

Refresh your Gateway and the todo app appears, live at the URL the deploy prints (`https://todo-<your-org>.your-domain.dev`). Open it and you're already logged in.

<details className="faq">
<summary>Why the Gateway needs a domain</summary>
<div className="faq-content">

The Gateway serves at your domain and each app at its own subdomain of it, so `npx everyapp gateway deploy` needs `--domain` the first time (it remembers it after). `workers.dev` addresses can't have subdomains, so they can't host apps. Any domain on your Cloudflare account works, including a cheap one bought just for this.
