You can build an app with Claude Code or Cursor in an afternoon. The hard part is putting it online for real people.

Every app needs a login, a database, hosting, a web address and a safe place for your AI keys. Every App sets all of that up once. After that, each new app gets it for free.

## What you get

- **One sign-in for all your apps**, at `apps.yourdomain.com`.
- **No login code to write.** Your app is simply told who the user is.
- **A database and a web address for each app**, like `todo.apps.yourdomain.com`.
- **Private by default.** Only people you invite can open your apps.
- **AI keys in one place.** Add your OpenAI key once and every app can use it.
- **One command to go live:** `pnpm run deploy`.

## What it costs

$5 a month for Cloudflare's Workers Paid plan, plus a domain (about $10 a year). There's no Every App bill. It's open source and runs in your own Cloudflare account. [Details](/docs/gateway#what-it-costs).

## How it fits together

- **The Gateway** is your front door. People sign in there, and it decides who can open what. You set it up once. [More](/docs/gateway).
- **Apps** are what you build. Each one sits behind the Gateway. [More](/docs/apps).

You don't need to know anything about servers. You just need to be OK pasting commands into a terminal, or letting your coding agent do it.
