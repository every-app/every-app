The Gateway is where you and the people you invite sign in and open your apps. Before you start, you need a [Cloudflare account on Workers Paid](/docs/cloudflare) and a [domain on Cloudflare](/docs/domain).

Using Claude Code, Codex or Cursor? It can run these steps for you. [Or let your coding agent do it](#or-let-your-coding-agent-do-it)

## Install the tools

1. **Node.js.** Download the LTS version from [nodejs.org](https://nodejs.org) and run the installer. You need version 22.18 or newer.
2. **A terminal.** On a Mac, open the **Terminal** app. On Windows, open **Windows Terminal**.
3. **pnpm.** In the terminal, run:

   ```bash
   npm install -g pnpm
   ```

4. **Git.** On a Mac, run `git --version`. If it isn't installed, your Mac offers to install it. On Windows, install it from [git-scm.com](https://git-scm.com).

## Set it up

<Steps>
<Step>

### Download EveryApp

```bash
git clone https://github.com/every-app/every-app.git
cd every-app
pnpm install
```

Run every command in these docs from this `every-app` folder.

</Step>
<Step>

### Start setup

```bash
pnpm everyapp setup
```

</Step>
<Step>

### Log in to Cloudflare

The terminal says **Log in to Cloudflare to continue**, then **Starting Cloudflare's login. Open its link and enter the code.** A Cloudflare page opens in your browser. Approve it there. If the page asks for a code, type the one the terminal shows.

If you have more than one Cloudflare account, the terminal asks which one to use.

What you're approving is Cloudflare's own sign-in for its `cf` command line tool, which EveryApp runs for you. Like `wrangler login`, it gives `cf` on this computer broad access to the Cloudflare accounts you belong to, not only the one you pick. EveryApp uses it for the Gateway, your apps and what you turn on later, like Cloudflare Access, and leaves everything else alone; setup stops rather than replace a DNS record that already exists. [What EveryApp puts in your account](/docs/cloudflare#what-every-app-puts-in-your-account)

If you'd rather not grant that, run setup with an API token instead. For setup, a token needs Account > Workers Scripts > Edit, Account > D1 > Edit, Account > Workers KV Storage > Edit, Zone > Zone > Read and Zone > DNS > Read, limited to this account and your domain; set `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID` before the command.

</Step>
<Step>

### Choose your address

The terminal asks for the **Gateway address** and suggests `apps.yourcompany.com`. Press Enter to use it, or type another name under your domain. [Choosing your address](/docs/domain#choosing-your-address)

</Step>
<Step>

### Wait a few minutes

Setup builds the Gateway and puts it online. This step usually takes 5 to 10 minutes; the whole setup about 15, most of the rest waiting for you at the owner link.

</Step>
<Step>

### Create your owner account

Your browser opens a page called **Set up your gateway**. Enter your name, email and a password of at least 8 characters (twice), then select **Create owner account**.

Back in the terminal, setup asks **Configure browser app installs?** Yes lets owners and admins install published apps from the Gateway's Admin page instead of the terminal; it asks for a Cloudflare API token (it tells you which permissions) and stores it as a secret on your Gateway, `CF_DEPLOY_TOKEN`. Press Enter to skip it for now. In a script, add `--yes` and setup answers No for you. You can turn it on later by running setup again.

Then it asks **Put Cloudflare Access in front of your Gateway?** Press Enter for Yes: people then sign in at Cloudflare's edge before they reach your Gateway or its apps, with their Cloudflare account or a code sent by email, and Cloudflare's free Zero Trust plan covers 50 people. If your Cloudflare account has no Zero Trust team yet, setup asks for a team name; people sign in at `<name>.cloudflareaccess.com`, and the name can't be changed later. In a script, or when an agent runs setup for you, Access goes on without a question when it can (your account has a Zero Trust team and your Cloudflare login is an owner or admin of the Gateway); otherwise setup says why and names `pnpm everyapp access on`. Add `--no-access` to leave it off. You can turn it off any time with `pnpm everyapp access off`, and on later with `pnpm everyapp access on`. [Sign in through Cloudflare Access](/docs/access)

</Step>
</Steps>

<Callout type="warn">
  The owner link works once and expires after about 24 hours. Anyone who opens
  it first becomes the owner, so don't share it. If you lose it, run `pnpm
  everyapp setup` again for a new one.
</Callout>

## When it's done

The terminal ends with your Gateway's address and what to do next:

```text
Gateway  https://apps.yourcompany.com
Admin    https://apps.yourcompany.com/admin  invite people, choose who opens which app
Access   on  everyone signs in through Cloudflare Access first

Next:
  pnpm everyapp create my-app                          start your first app
  pnpm everyapp secret set OPENAI_API_KEY              AI for apps (or OPENROUTER_API_KEY, WORKERS_AI_API_TOKEN)
  pnpm everyapp secret set EMAIL_FROM EMAIL_FROM_NAME  email invites and password resets; needs Cloudflare Email Sending
```

Open it and you're signed in.

Apps that use AI need a key on your Gateway: OpenAI, OpenRouter or Workers AI. [Apps that use AI](/docs/create-an-app#apps-that-use-ai)

Email is optional. With it, invites go out by email. [Send email](/docs/people#send-email)

If you said No to Cloudflare Access, the list also shows `pnpm everyapp access on`. Before you invite anyone, we strongly recommend it: one command, and people sign in with their Cloudflare account or a code by email before they reach your Gateway. [Sign in through Cloudflare Access](/docs/access)

## If setup stops

Run `pnpm everyapp setup` again. It picks up where it left off. [Troubleshooting](/docs/troubleshooting) covers the common reasons it stops.

## Add it to your phone

Open `https://apps.yourcompany.com/pwa` on your computer and scan the code with your phone, or open that address on your phone and follow the steps. Your apps then open from your home screen.
