EveryApp is in early development, so expect some rough edges. Thank you for trying it this early. If you'd rather skip the rough edges, come back in a few weeks.

## What's rough today

- Setup takes about 15 minutes and sometimes more: it downloads the Gateway, deploys it, then waits for a certificate.
- Some apps show **Needs setup** until you add their keys. `everyapp configure <app>` sets them.
- The docs can lag behind the code by a day or two.

## Get help

- Ask in our [Discord](https://discord.gg/c9uGs3cFXr). Run the command again with `--verbose` at the end and bring the output.
- Open an issue on [GitHub](https://github.com/every-app/every-app/issues).
- Email [support@everyapp.dev](mailto:support@everyapp.dev).

Expect a fast, informal reply from a very small team. [Troubleshooting](/docs/troubleshooting) covers the errors we already know.

## Tell us what could be smoother

Small things count: a confusing step, a message that didn't say what to do, a wait that felt too long. A line in Discord or a GitHub issue is enough.

## Stay up to date

```bash
npm install -g everyapp@latest
everyapp update
```

Your people, apps and data stay.

Deploys keep your data and save a restore point before changing a database. [Undo a database change](/docs/update#undo-a-database-change) We don't promise backwards compatibility yet; the release notes say what changed.

⭐ [Star the repository](https://github.com/every-app/every-app) to follow along.
