# Chef

> **Standalone Docker self-hosting is not supported for Chef under Every App
> v2.** Chef requires the identity configuration and gateway service binding
> generated by the Every App CLI. Use `npx everyapp app deploy` for a production
> deployment behind the gateway, or `npx everyapp dev` for local development.

## Development

Build the workspace SDK, add a local OpenAI key, and run Chef behind the local
Every App gateway:

```sh
pnpm -C ../../packages/sdk build
cp .dev.vars.example .dev.vars
# Set OPENAI_API_KEY in .dev.vars
pnpm dev
```

The SDK uses `OPENAI_API_KEY` directly only in local development. Production
deploys receive the private `EVERY_APP_GATEWAY` service binding from
`everyapp app deploy`; Chef does not need an app token or provider key there.

Use `pnpm dev:vite` only for bare Vite debugging. Authenticated routes expect
the gateway started by `pnpm dev`.
