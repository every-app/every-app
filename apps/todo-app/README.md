# Todo Example App

## Development

From your terminal, run the app behind the local gateway in stub mode:

```sh
pnpm install
pnpm dev
```

Use `pnpm dev:vite` only when you intentionally need the bare Vite server;
SDK-protected routes require the gateway started by `pnpm dev`.
