# Hosted Every App: final build plan for the night of 2026-10-15/16

**One codebase, one switch.** Every hosted behaviour sits behind `platformPolicy(env)`, a frozen object read from `GATEWAY_DEPLOYMENT_MODE` (`self_hosted | hosted | invalid`, fail-closed). Self-host stays the default and stays byte-for-byte what it is today; `invalid` behaves like today with every hosted switch off.

Three decisions reshape the draft plan; everything below follows from them:

1. **Shared first-party apps are a flag, not a table.** A first-party app (OpenSEO, todo) is one `apps` row with `scope = 'shared'`, owned by a platform organization row we create, one hostname, one Worker, reached over `APP__<worker>` exactly as today. Access is live membership in the session's organization; the organization is the session's active org. No install rows, no catalog table, no per-org hostnames.
2. **Hosts keep today's invariant.** Control plane `app.everyapp.com`, `APP_BASE_DOMAIN = app.everyapp.com`, first-party apps at `<app>.app.everyapp.com` as Workers Custom Domains (per-host certificates, the mechanism the live self-host install already relies on), one Better Auth cookie `Domain=app.everyapp.com`. Third-party hosts (`*.everyapp.dev`) fail closed until Lane F ships the per-host handoff.
3. **The gateway bills nothing tonight.** OpenSEO keeps its own Autumn, DataForSEO, OpenRouter and Loops inside its own Worker with Autumn customer id = gateway `organizations.id`. The shared-key OpenAI proxy is off in hosted until a wallet exists, so chef is not in the hosted catalog on day one.

Critical path for "OpenSEO works on day one": **PR 1 → PR 2 → PR 6 → PR 7**, with the three OpenSEO PRs developed concurrently against the contract in the last section and labelled "mergeable, not deployable" until PR 7 is green. Nothing can be deployed to Cloudflare tonight (read-only API token); the morning starts with the ops list at the end.

## Rules for the night

### The gateway contract OS-1..3 depend on

**Inbound to OpenSEO (set by the gateway, never by a client; every inbound `x-everyapp-*`, `Cookie`, `cf-access-*` is stripped first):**

| Header | When | Content |
|---|---|---|
| `x-everyapp-identity` | signed-in member with access | RS256 JWT, header `alg: RS256`, `kid: everyapp-identity` (dev: `everyapp-identity-dev`, only with `iss = https://gateway.dev.localhost`) |
| `x-everyapp-public` | anonymous visitor on a manifest-declared public route | JWT `typ: "public"`, `pub: true`, `jti`; same `iss`/`aud`/keys |
| `Authorization` | forwarded only on public routes, and never when it is a gateway credential (`epat_`, gateway OAuth) | opaque to the gateway (svix and other webhook signatures arrive as their own headers) |

Identity JWT claims (`packages/sdk/src/internal/protocol.ts`):

```
iss      = https://app.everyapp.com            (EVERYAPP_IDENTITY_ISSUER)
aud      = "openseo"                            (the app id; EVERYAPP_AUDIENCE on the OpenSEO side)
sub      = gateway user id          email = user email
typ      = "user"
org_id   = gateway organizations.id (always present; the active org, membership-verified per request)
org_role = "owner" | "admin" | "member"
chan     = "web" | "api" | "mcp" | "agent"     act = { sub }     scopes = ["*"] or a PAT's scopes
jti, iat, exp (exp - iat = 120 s)
```

**OpenSEO Worker env (set by the Alchemy stage from values the gateway publishes):**

| Var | Value |
|---|---|
| `EVERYAPP_IDENTITY_PUBLIC_KEYS` | JSON array of PEM public keys (the gateway's `JWT_PUBLIC_KEY`, rotated keys appended) |
| `EVERYAPP_IDENTITY_ISSUER` | `https://app.everyapp.com` |
| `EVERYAPP_AUDIENCE` | `openseo` (OpenSEO's own name for the expected `aud`; equals the gateway app id) |
| `EVERYAPP_DEV` | `1` only for local runs against `everyapp dev` (accepts the dev kid and issuer) |

**Registry entry (`hosted/catalog.json`, PR 7):** `{ "appId": "openseo", "workerName": "open-seo-everyapp", "hostname": "openseo.app.everyapp.com", "dataScope": "org", "manifest": { "id": "openseo", "public": ["POST /api/autumn/webhook", "GET /r/*", "GET /api/ai-visibility/download", "<GDPR_STORAGE_ERASURE_PATH>"], "providers": [], "mcp": "none" } }` — everything not listed is auth-required and reaches OpenSEO with an identity JWT; `/mcp` is not public and is off in OpenSEO.

**Bindings and headers not used on day one but reserved:** the `EVERY_APP_GATEWAY` service binding to the gateway's `AppGateway` entrypoint with props `{ appId, workerName, scope: "shared" }` (PR 6), and `x-everyapp-org` on calls that carry no identity JWT (Workflows, crons), checked against a live organization row; these become live when the money lane lands.
