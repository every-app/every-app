# Simplify the repository before launch (2026-10-24)

This is the execution plan for cutting the repository down to a simpler foundation before Monday's launch (2026-10-27). It was drawn from ten read-only inventories of the checkout at `bc3fe476`, two adversarial refutation passes over every proposed deletion (270 verdicts, 40 amendments applied), three design reviews (CLI framework, repo structure, the MCP line), and Ben's decisions of 2026-10-24 (section 1). Stages, one pull request each, smallest blast radius first: stage 1a deletes the example apps (`apps/todo-app`, `apps/workout-tracker`, `apps/chef`, `apps/mobile-native`) and the example-era material (PR #427); stage 1b deletes the historical documents and the Docker path and adds `docs/hosted-vision.md`; #442 removes the gateway's mobile-only auth code; stage 2 removes dead CLI flags, the hosted-only CLI surface and the legacy MCP material; stage 3 consolidates structure (one lockfile, `packages/cf-rest` into the gateway, `templates/simple-todo` to `starter/`); stage 4 is the CLI language PR (`gateway deploy` to `update`, `deploy` for a folder and `install <url>` for a release and `release` to pack one, `workflow` and bash completion deleted, stricli kept and shrunk), after the sibling threads' CLI PRs merge. Throughout: `everyapp.team` keeps working (six live apps when the plan was drawn; four since the todo and postiz deletions, see Status), security-boundary code (`apps/every-app-gateway/src/auth`, `src/server`) goes in PRs held for Ben, and nothing a sibling launch thread is editing this weekend is touched without a message first. Line numbers below are from `bc3fe476`; `TODO.md` numbers in particular have shifted on origin/main.

Stay on stricli and shrink it.
